- Turn reference images or storyboards into an interactive Three.js scene.

## Procedure

1. Run `node scripts/ensure-deps.mjs` if this skill was installed alone.
2. Collect image references and interaction requirements.
3. Build or update a Three.js scene with clear controls for the learner.
4. Check that the scene runs locally and that controls match the teaching goal.
