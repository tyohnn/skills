# Anti-patterns

고치면 되는 패턴만 모았다. 전부 금지 단어 목록이 아니라, “이렇게 나오면 AI 티” 나는 쪽이다.

## 단정 연타

연속으로 `~다. ~다. ~다.`만 쌓으면 설명처럼 안 들린다.

- bad: `이 변경은 필수다. 성능이 좋아진다. 리스크는 낮다.`
- better: `이 변경이 필요해서 넣었고, 성능은 나아지는데 리스크는 낮은 편이에요.`

## 가짜 힘 동사

번역투·컨설팅 톤 동사. 평소에 안 쓰는 말이다.

| 피하기 | 대신 |
| --- | --- |
| 박다 / 각인하다 | 넣다, 남기다 |
| 살리다 | 쓰다, 살리다(진짜 살리는 경우만) |
| 심다 | 넣다, 두다 |
| 세우다(원칙을 세우다 등) | 정하다, 쓰다 |
| 끌어올리다 | 올리다, 개선하다 |
| 열어젖히다 | 열다, 가능하게 하다 |
| 관통하다 | 지나다, 걸치다 |
| 직조하다 / 직관하다(誤) | 짜다, 연결하다 |

## 선언 헤더·구조 연출

본문 앞에서 목차처럼 까는 말.

- `핵심은 이거예요.`
- `정리하면 다음과 같습니다.`
- `무엇을 왜 했나요?`
- `부수 이득`
- `한 줄 요약:` (답변 첫머리에 습관적으로)

그냥 말 시작하면 된다.

## 문어·교과서 과다

- `이에 따라`, `상기한`, `본 변경은`, `하기와 같이`
- `~함에 있어`, `~으로써`, `~을 위함이다`

평소 말로: `그래서`, `위에서 말한`, `이 변경은`, `이렇게`.

## 이상한 어휘·번역투

- `레버리지하다`, `임팩트를 만들다` → `활용하다`, `영향을 주다` / 그냥 구체적으로
- `유저 저니를 프레이밍하다` → `사용 흐름을 이렇게 보면`
- `~를 통해 ~를 가능하게 한다` → `~해서 ~할 수 있어요`

## 과한 구어

구어는 허용이지만 매 문장 `근데/그냥/좀`이면 산만하다.
문단당 한두 번이면 충분하다.
