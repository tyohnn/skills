Data model and System model are index-only folders (like PRDs). Product-specific
surfaces (for example a CLI) are optional and are not part of the default Spec
sidebar.

| Boundary | Role |
|---|---|
| [Data model](/docs/spec/data-model) | Entities, IDs, and invariants |
| [System model](/docs/spec/system-model) | Routes, IA, and runtime boundaries |
